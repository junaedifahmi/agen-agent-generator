Agen Elicitation Flow

Agen never derives "what's left to ask" from the transcript. Every turn re-checks a small tracked record in session state, and the one action with real consequences — generating the chatbot — sits behind an explicit pause that only a human can release. The diagram below is the actual control flow, not the conversation: four lanes (who acts), one recheck loop, one confirmation gate, and four distinct exception paths that all fold back into the same loop rather than dead-ending.
